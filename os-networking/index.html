Operating Systems & Networking — The Full Course

Fifty self-contained, interactive lessons on the two layers every backend system stands on — the operating system and the network. From the kernel boundary, processes, scheduling, concurrency, virtual memory and file I/O, through Ethernet, IP, TCP, DNS, TLS and HTTP/3, to containers, eBPF and production debugging. Organised bottom-up and dependency-aware: the machine first, then the wire, then where the two meet inside a running Linux server. Every lesson runs the same way — a clear mental model, schematic play-through diagrams, real commands, and a self-test.

Original study material. Built from scratch for engineers preparing for backend, infrastructure, and platform interviews — and for the real work behind them. The framing draws on the Linux kernel documentation, the man pages and the IETF RFCs for accuracy, but every explanation, diagram, and line of code is original. Operating-system examples target Linux — the 7.x stable line and the 6.18 LTS kernel, current as of late 2026, including EEVDF as the default scheduler, sched_ext, cgroup v2 and io_uring. Networking tracks TCP (RFC 9293), TLS 1.3, HTTP/2, QUIC and HTTP/3, and the hybrid post-quantum key exchange that OpenSSL 3.5 and the major browsers now use by default. Version details are treated as illustrative throughout, because kernel and protocol defaults keep moving.
How to use it

Do L00–L03 first — the kernel boundary, the cost ladder and the three tools you'll keep reaching for carry through every later lesson. Then the course splits into two halves you can walk in parallel: the machine (P1–P5) and the wire (P6–P8); P9 and the capstone need both. The guiding rule throughout: name the layer before you name the fix — a slow request is a scheduling, memory, disk, or network problem first, and the right tool follows from which. Short on time? The ★ Core 18 are the highest-yield path.
